# Study Planner

A simple and user-friendly Study Planner web application built using React and Vite.

The application helps students organize their study tasks by adding a subject, task name, and due date. Users can also mark tasks as completed and delete tasks when they are no longer needed.

## Features

- Add new study tasks
- Add a subject for each task
- Set a due date
- Mark tasks as completed
- Delete tasks
- Manage multiple tasks
- Simple and clean user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- React
- Vite
